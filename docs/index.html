Get started

Add the DLL as a project reference, then choose a generator and a seed:

using RandEXom.RandomLib;

var random = new ModuloRandom(seed: 12345);
int value = random.NextInt(0, 100); // 0 through 99

Minimum bounds are inclusive; maximum bounds are exclusive. The source is available in the GitHub repository.
