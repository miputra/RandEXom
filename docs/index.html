RandEXom · v1.5b

Build the randomizer you need.

RandEXom is a C# library with interchangeable seed generators, bounded random sources, and helpers for weighted picks, percentages, shuffles, and number ranges.

Get started

Add the DLL as a project reference, then choose a generator and a seed:

using RandEXom.RandomLib;

var random = new ModuloRandom(seed: 12345);
int value = random.NextInt(0, 100); // 0 through 99

Minimum bounds are inclusive; maximum bounds are exclusive. The source is available in the GitHub repository.

For more examples of seeded generators, shuffling, weighted draws, and percentages, read the usage guide.

What changed in v1.5b

This release corrects LCG and xorshift64* transitions, bounded sampling, weighted draws, and several range helpers. Seeded output sequences may differ from earlier releases. Review the README and verification checks for details.
