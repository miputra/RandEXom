3.3 Framework.Item

Chapter 3: Framework helpers · Section 3 · Guide map

This branch of Framework uses random draws to reorder a list or select items from a pool. Its three public helpers live in RandEXom.Framework.Item: Shuffles_FisherYates, GachaR<T>, and GachaRBatched<T>. Each can be constructed with a numeric seed or a shared IRandomR source. A shared source makes call order matter across helpers. Both gacha variants implement IGachaR<T>; shuffle does not.
